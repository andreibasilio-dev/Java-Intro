Hello! Welcome to my very first repository called Java-Intro.
This repository contains all my very first and very simple Java Projects showing my understanding about the fundamentals of Java Programming Language.

This repository will contain the projects related to the topics like:
1. Printing an output in the program using 'System.out.print() and System.out.println()';
2. Formatting the output of the program using \t, \n, and \".
3. Enter an input from the keyboard using the Scanner.
4. Using data types based on values it stores.
5. Performing arithmetic operations using operators.
6. Make conditional statements using 'if-else' statement.
7. Iterate using 'while' and for 'loops'; and
8. Storing and retrieving values using 'Array'.

Projects:
1. FirstJava.java : A short introduction program about myself using 'System.out.print() and System.out.println()'.
2. SimpleConsoleInvoice.java : A simple text based invoice program with 10 products and total. Formatting using \t \n and \".
3. GroceryShopCalc.java : A simple interactive program that asks the user to input using a Scanner, then calculates the final total.
4. AreaPerimeterRecCalc.java : A text based program that calculates area & perimeter rectangle calculator.
5. GroceryDiscCalc.java : A program that asks the user to enter the total amount of their grocery, check the discount using if else, and calculates the final total.
6. RestaurantOrderSystem.java : A program that asks the user to select order from the menu, check the order using the switch statement, and calculates the final total.
7. AttendanceSystem.java : A program that checks the no. of students in a class then asks if a student is present or absent with switch statement multiple times using a loop.
8. PasswordValidationSystem.java : A program that evaluates the password given by the user if it met the requirements using if else and character class multiple times using a loop.
   
That's all! See you on my next repository!
